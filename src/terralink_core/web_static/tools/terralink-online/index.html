TerraLink - Wildlife Habitat Connectivity Tool

Restoring ecological connectivity is essential for biodiversity, climate resilience, and long-term ecosystem stability. TerraLink helps identify where corridors can reconnect fragmented habitats so species can move, adapt, and persist across working landscapes. Upload a zipped shapefile, GeoJSON, KML, or GeoTIFF, set corridor width, budget, and patch thresholds, choose from four optimization modes, then review contiguous areas, corridor outputs, and connectivity metrics directly on the map. Try TerraLink with your own data below and  read more about TerraLink here .
