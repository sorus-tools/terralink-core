# TerraLink core development

Preserve algorithm behavior unless a deliberate method/profile change is documented.
Run targeted conformance and feasibility tests when changing geometry, routing,
selection, accounting, or metrics. A matching aggregate metric alone is not parity.
Keep QGIS, Qt, cloud accounts, and web frameworks out of the standalone API.
The preserved `_engine` source has upstream hashes in `source-provenance.json`.
Document modifications and exercise actual active paths. Do not substitute a new
greedy algorithm for the existing four strategies.
Native R remains an independent implementation; never claim equivalence without
the corresponding fixture comparison. Do not edit a user's existing dirty source
tree destructively. Do not publish uploads, environment values, or private snapshots.
